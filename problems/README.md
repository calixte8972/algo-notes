# 题目笔记

这里记录的是「你如何得到答案」，而不是只记录答案。

## 每题必须留下的内容

- 用自己的话改写题意。
- 至少一个手算例子，包含你关心的边界。
- 最初的思路与它为什么不够好（如果有）。
- 核心观察：为什么这个算法适用。
- 正确性理由：为什么不会漏、不会重，或为什么状态定义足够。
- 时间与空间复杂度。
- 你的错误、陌生点和下次识别它的信号。

## 状态标签

在题目笔记开头使用以下状态之一：

- `未开始`：只收集了题目。
- `思考中`：还没有看完整解法。
- `已完成`：已独立说明思路并写出实现。
- `待复习`：已经做过，但还不能稳定重做。
- `已掌握`：不看笔记也能识别模式、说明原因并实现。

从 [`../templates/problem.md`](../templates/problem.md) 复制模板开始。
